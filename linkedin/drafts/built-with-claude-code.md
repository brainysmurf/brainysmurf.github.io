I finally built my personal site. Not "this weekend." Actually built it.

Here's the thing nobody tells you about personal projects: the blocker isn't technical skill. It's decisions. Which framework, which theme, what to write, does anyone even read blogs.

So I tried something different. I wrote a detailed brief — the kind I'd write for my team — and handed it to Claude Code, Anthropic's AI coding agent.

The result: three complete themes, responsive layouts, a deployment pipeline, and content — all in a single session.

What worked:
→ Speed. What would normally be a weekend project took an afternoon.
→ Consistency. Every component follows the same design token system. No "tired at 11pm" inconsistencies.
→ The boring parts. Config files, GitHub Actions YAML, meta tags — handled without complaint.

What surprised me:
→ The agent asked clarifying questions. It pushed back when my brief had contradictions.
→ Its design instincts were better than expected.
→ The output quality was directly proportional to how specific my brief was.

The takeaway: AI didn't replace me. It compressed the tedious middle of the project — the part between "I know what I want" and "it's live."

That middle part is where personal projects go to die. This one survived.
